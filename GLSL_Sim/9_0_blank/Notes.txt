VALUE / GRADIENT NOISE
    
    Value Noise:
        -lattice or grid of random vals
        -sample from grid 
        -blend the vals from the grid

    Gradient noise:
        -Instead of VALUES, uses random unit length vector
        -so instead of blending, you calc the dot of each unit len vector of the 4 surrounding examples

PERLIN AND SIMPLEX

    Fractal brownian motion (FBM)
        -movements arent fully independent (memory remains)
        -There is a momentum to it.
        - multiply amplitude or sin(x) * amp to get higher amplitudes
        - frequency change is mul in the sin function
        - Stacking Y with the SIN frequencies will make them stack all of the sin waves on top of each other
    Code EX:
    float FBM(vec3 position)
    {
        float amplitude = 0.5;
        float frequency = 1.0;
        float total = 0.0;
    
        for (int i = 0; i < OCTAVES; i++)  //OCTAVES IS THE NUMBER OF TIMES YOU LOOP
        {
            total += noise(position * frequency) * amplitude;
            amplitude *= PERSISTANCE;     // HERST component
            frequency *= LACUNARITY;
        }

        return total;
    }

    Cellular noises:
        - "Think of a grid of cells, and in each cell there is a point that is offset in each cell"
        - 'Treat it as a distance field'
        - 'To calculate, take the min of distance the offset points in the nearest cells, that leaves you with the noise value'
